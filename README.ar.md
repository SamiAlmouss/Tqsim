# Tqsim

[English](README.md) | [العربية](README.ar.md)

**أداة تقسيم ودمج آمنة للملفات على Windows · إصدار الصيانة 1.0.8 · ترخيص MIT**

يقسم Tqsim الملفات الثنائية الكبيرة إلى أجزاء مناسبة للرفع والنقل، ثم يستعيد البايتات الأصلية باستخدام الأجزاء وملف الوصف. يناسب نقل النسخ الاحتياطية وتجاوز حدود الرفع والتحقق من الملفات المنزلة وتشفير الأجزاء قبل تخزينها. لا تحتاج إلى الملف الأصلي عند الاستعادة.

تظل الهوية الطرفية CyberHorror محفوظة: ثلاثة شعارات ASCII عشوائية، وألوان مستقلة للشعار والحالة، وشعار في المنتصف، وتقدم في سطر وحالته في سطر يتضمن الحجم والسرعة والوقت المتبقي. تدعم الأداة `-NoLogo` و`-NoColor` و`NO_COLOR` و`-Quiet`.

## المزايا والمتطلبات

تقسيم ثنائي متدفق ودمج دون فقد، وأحجام وإزاحات Int64 تدعم ملفات تتجاوز 4GB، وذاكرة محدودة لبيانات الملفات. بصمات SHA-256 لكل جزء وللمصدر، وقراءة مستقلة إضافية مفعلة افتراضيًا. تشفير اختياري AES-256-GCM مع اكتشاف تلقائي عند الدمج والتحقق، وحذف اختياري للمصادر بعد النجاح، وحماية من تعارض الوجهة وتقارير للتنظيف الجزئي. تعمل المعالجة دون إنترنت بعد التثبيت ولا تُنزَّل مكتبات تشفير خارجية. تبقى الأرشيفات القديمة غير المشفرة متوافقة.

يتطلب التطبيق **Windows وPowerShell 7 أو أحدث**. يمكن لمثبت الأداة البدء من Windows PowerShell 5.1 وتسليم التنفيذ إلى PowerShell 7 المثبت، لكن 5.1 لا يشغل معالجة الملفات. لتثبيت PowerShell:

```powershell
winget install --id Microsoft.PowerShell --source winget
```

افتح طرفية `pwsh` جديدة. التخزين المحلي Windows/NTFS هو بيئة الاختبار؛ تستخدم الملفات المؤقتة المفكوكة وحماية الحذف واجهات Windows. لم تُعتمد Linux/macOS أو ضمانات أعطال التخزين الشبكي أو كل إصدارات PowerShell 7 الأقدم. اختُبر المحرك في 1.0.6 على 7.6.5 و7.6.9؛ انظر [النتائج الفعلية](docs/VALIDATION-v1.0.6.md). تُرفض وجهات تحتوي روابط مجلدات أو junctions. وفر المساحة واحتفظ بنسخة مستقلة.

## التثبيت

[المستودع الرسمي](https://github.com/SamiAlmouss/Tqsim) · [الإصدارات الرسمية](https://github.com/SamiAlmouss/Tqsim/releases)

```powershell
irm https://raw.githubusercontent.com/SamiAlmouss/Tqsim/main/install.ps1 | iex
```

ينفذ هذا الأمر نصًا من الإنترنت ويتطلب الثقة بالناشر. البديل الأفضل للفحص قبل التنفيذ:

```powershell
Invoke-WebRequest https://raw.githubusercontent.com/SamiAlmouss/Tqsim/main/install.ps1 -OutFile install.ps1
Get-Content ./install.ps1
# اقرأ الملف قبل تنفيذ السطر التالي:
pwsh -NoProfile -File ./install.ps1 -Repository SamiAlmouss/Tqsim
```

ينزل المثبت أحدث إصدار مستقر وملف البصمة، ويتحقق من هوية الأصول وأحجامها وSHA-256 ومسارات ZIP، ثم يجهز الإصدار ويبدل مؤشر التثبيت مع التراجع عند الفشل. تطابق البصمة لا يثبت هوية الناشر مستقلًا. الموقع الافتراضي `%LOCALAPPDATA%\Programs\Tqsim`؛ يضيف `bin` إلى PATH للمستخدم دون تعديل ملفه الشخصي أو طلب صلاحيات المدير.

في PowerShell 7 يستمر طبيعيًا، وفي 5.1 يبحث عن `pwsh.exe` ويختبره، بما فيه تثبيت Store أو المستخدم، ثم يعيد تشغيل وظائف المثبت المحملة في عملية منفصلة. لا يعتمد على PSScriptRoot/PSCommandPath، ويمنع حلقات إعادة التشغيل ويحافظ على حالة الخطأ ولا يغلق نافذة المستخدم الأصلية. لا يثبت PowerShell تلقائيًا ولا يتجاوز سياسة التنفيذ. افتح طرفية جديدة بعد التثبيت، خصوصًا بعد التسليم من 5.1، ثم شغّل `tqsim version -NoLogo`. [تفاصيل المثبت](docs/INSTALLER-BOOTSTRAP.md).

## البداية السريعة

المسارات أمثلة؛ استبدلها بملفات تجريبية تخصك:

```powershell
tqsim split -File "D:\backup.iso" -Size "1GB"
tqsim verify -PartsPath "D:\Output"
tqsim merg -PartsPath "D:\Output"
```

ينشئ التقسيم أجزاء `backup.iso.part0001` وما يليها وملف `backup.iso.tqsim.json` في `D:\Output`، ويبقي المصدر ويقرأ الأجزاء للتحقق افتراضيًا دون تشفير. يفحص verify الأطوال والبصمات دون إنشاء ملف أو حذف بيانات. يعيد merg الملف إلى **`D:\Output\backup.iso` مباشرة داخل مجلد الأجزاء** دون مجلد Output إضافي، ويبقي الأجزاء. استبدال ملف مستعاد موجود يتطلب `-Overwrite` صراحة.

ارفع أو انقل جميع الأجزاء وملف الوصف الأصلي معًا دون تعديل. يمكن الاستعادة على جهاز آخر دون المصدر. عند وجود عدة ملفات وصف، اختر باستخدام `-Manifest`.

## مرجع الأوامر

تدعم كل الأوامر `-NoLogo` لإخفاء الشعار، و`-NoColor` لإلغاء ألوان Tqsim، و`-Quiet` لتقليل المخرجات الروتينية والتقدم مع بقاء المساعدة والنتائج المطلوبة والأخطاء والتحذيرات، و`-Diagnostics` لتفاصيل الأخطاء. كلها مفاتيح معطلة افتراضيًا. قد تبقى رسائل مستقلة للمثبت. انظر [مرجع المعاملات الكامل](docs/PARAMETERS.md) و[كل صفحات المساعدة](docs/COMMANDS.md) باللغة الإنجليزية؛ أسماء الأوامر والمعاملات لا تُترجم.

### split

```powershell
tqsim split -File <path> -Size <size> [-Output <directory>] [-ds <true|false>] [-verify <true|false>] [-encrypt <true|false>] [-BufferSize <bytes>]
```

| المعامل | الافتراضي أو السلوك |
| --- | --- |
| `-File` و`-Size` | مطلوبان: المصدر وأقصى حجم فعلي للجزء |
| `-Output` | مجلد Output بجوار المصدر |
| `-ds` و`-verify` و`-encrypt` | false وtrue وfalse |
| `-BufferSize` | 4194304 بايت؛ عدد صحيح بين 4096 و67108864 |

الأحجام أعداد صحيحة موجبة بالبايت أو B أو KB/KiB أو MB/MiB أو GB/GiB أو TB/TiB، دون كسور أو مسافات أو سالب، وبحد Int64 الموجب بعد التحويل. كل الوحدات ثنائية: `1GB = 1GiB = 1,073,741,824` بايت. للجيجابايت العشري استخدم `1000000000`. الحد الأدنى للجزء المشفر 29 بايت. تُسمى الأجزاء باسم المصدر مع `.part0001` وما يليها؛ لا استبدال صامت. المصدر الفارغ ينتج ملف وصف دون أجزاء.

```powershell
tqsim split -File "D:\backup.iso" -Size "2GB"
tqsim split -File "D:\backup.iso" -Size "1GB" -Output "E:\MyParts"
tqsim split -File "D:\backup.iso" -Size "1GB" -verify "false"
tqsim split -File "D:\backup.iso" -Size "1GB" -ds "true"
tqsim split -File "D:\backup.iso" -Size "1GB" -encrypt "true"
tqsim split -File "D:\backup.iso" -Size "1GB" -encrypt "true" -ds "true"
```

الوضع الأسرع `-verify false` يتجاوز القراءة المستقلة ويقلل ضمان التحقق، مع بقاء فحوص التدفق. يطلب التشفير كلمة مرور مخفية وتأكيدها. احفظها وأثبت الاستعادة ببيانات تجريبية قبل حذف مصدر مهم؛ فقدانها يمنع الاستعادة. الفشل أو الإلغاء قبل التنظيف يبقي المصدر، لكن قد تبقى مخرجات جزئية؛ افحصها واستخدم وجهة جديدة للمحاولة التالية.

### merg

```powershell
tqsim merg [-PartsPath <directory>] [-Manifest <path>] [-Output <directory>] [-Overwrite] [-ds <true|false>] [-verify <true|false>] [-BufferSize <bytes>]
```

| المعامل | الافتراضي أو السلوك |
| --- | --- |
| `-PartsPath` | مجلد العمل الحالي |
| `-Manifest` | اكتشاف ملف .tqsim.json واحد؛ المسار الصريح يتجاوز الاكتشاف |
| `-Output` | مجلد ملف الوصف المختار؛ بجوار الأجزاء مباشرة |
| `-Overwrite` | معطل؛ يسمح باستبدال الملف النهائي الموجود صراحة |
| `-ds` و`-verify` | false وtrue |
| `-BufferSize` | 4194304 بايت؛ من 4096 إلى 67108864 |

```powershell
tqsim merg -PartsPath "E:\Parts"
tqsim merg -PartsPath "E:\Parts" -Output "D:\Restored"
tqsim merg -Manifest "E:\Parts\backup.iso.tqsim.json"
tqsim merg -PartsPath "E:\Parts" -ds "true"
tqsim merg -PartsPath "E:\Parts" -verify "false"
tqsim merg -PartsPath "E:\Parts" -ds "true" -verify "false"
tqsim merg -PartsPath "E:\EncryptedParts"
```

عند تحديد Manifest صراحة، تُقرأ الأجزاء من مجلده حتى لو حُدد PartsPath أيضًا. المسار النسبي لملف الوصف يُحسب من مجلد العمل الحالي. يكتشف الدمج التشفير ويطلب كلمة المرور مرة واحدة؛ لا يقبل `-encrypt` أو كلمة مرور كمعامل. كلمة المرور الخاطئة أو فشل السلامة الإلزامية يمنع اعتماد الاستعادة وحذف المصدر. القراءة المستقلة الاختيارية تحدث بعد إنشاء الملف النهائي وقبل الحذف؛ إذا فشلت قد يبقى الملف النهائي وتُحفظ المصادر. الحذف السريع دون قراءة مستقلة أقل ضمانًا ويُظهر تحذيرًا.

### merge

مرادف مطابق لـ merg في الصيغة والمعاملات والقيم والحماية، وليس أي منهما مهملًا:

```powershell
tqsim merge -PartsPath "E:\Parts"
```

### verify

```powershell
tqsim verify [-PartsPath <directory>] [-Manifest <path>] [-BufferSize <bytes>]
tqsim verify -PartsPath "E:\Parts"
```

| المعامل | الافتراضي |
| --- | --- |
| `-PartsPath` و`-Manifest` | المجلد الحالي واكتشاف ملف وصف واحد؛ الصريح يتقدم |
| `-BufferSize` | 4194304 بايت؛ من 4096 إلى 67108864 |

يفحص البنية والترتيب والأطوال وبصمة كل جزء وبصمة المصدر الكاملة. يطلب للأرشيف المشفر كلمة المرور ويصادق ملف الوصف وسجلات GCM وسلامة النص المفكوك دون كتابته. القديم غير المشفر لا يطلب كلمة مرور. الجزء المفقود أو التالف يفشل بحالة غير صفرية. لا يعيد إنشاء ملفات ولا يحذف أو يعدل بيانات المصدر والوصف. **الأمر verify مستقل عن خيار `-verify` الخاص بالتقسيم والدمج**؛ لا يقبل `-verify` أو `-ds` أو `-encrypt` أو `-Output` أو `-Overwrite`.

### info

```powershell
tqsim info [-PartsPath <directory>] [-Manifest <path>]
tqsim info -PartsPath "E:\Parts"
tqsim info -Manifest "E:\Parts\backup.iso.tqsim.json" -NoLogo
```

| المعامل | الافتراضي |
| --- | --- |
| `-PartsPath` و`-Manifest` | المجلد الحالي واكتشاف ملف وصف واحد؛ الصريح يتقدم |

يعرض الاسم والحجم الأصلي والمقروء، وأقصى حجم معلن للجزء وعدد الأجزاء وSHA-256 الأصلي وتاريخ UTC وإصدار التطبيق والوصف. لا يسرد أحجام كل جزء أو حقل حالة تشفير صريحًا؛ الإصدار 2 يدل على بيانات وصف مشفرة. يفحص البنية فقط دون بصمات الأجزاء أو مصادقة HMAC أو طلب كلمة مرور. لا تثق بالبيانات المعروضة قبل نجاح verify أو الدمج.

### update

```powershell
tqsim update
```

المفاتيح العامة فقط؛ لا معاملات خاصة. يحتاج تثبيتًا مُدارًا واتصالًا بالإنترنت، ويفحص أحدث إصدار مستقر ويطبقه إن كان أحدث أو يخبرك بأن المثبت حالي. لا خيار للفحص فقط ولا تأكيد تفاعلي. تبقى حماية البصمة والتجهيز والتراجع ولا تتغير الأرشيفات. لا يحدث نسخة المصدر. عرض version لا يفحص توفر تحديث.

### uninstall

```powershell
tqsim uninstall
```

المفاتيح العامة فقط؛ لا معاملات خاصة ولا رسالة تأكيد. يتطلب تثبيتًا مُدارًا، ويحذف ملفات التطبيق المعروفة والمشغل ومؤشر التثبيت ومدخل PATH الخاص به. تُحذف مجلدات التطبيق الفارغة، وعند خلو التثبيت تُزال علامة الملكية والجذر أخيرًا. عند بقاء ملفات أو مجلدات أخرى تُحفظ مع علامة الملكية لتبقى إعادة التثبيت ممكنة. لا تتغير سجلات الاستعادة. افتح طرفية جديدة لتحديث PATH. ليس أمر تنظيف للأجزاء ولا يحذف نسخة المصدر البرمجية.

### version

```powershell
tqsim version -NoLogo
tqsim --version -NoLogo
```

المفاتيح العامة فقط. يعرض version.json حتى مع Quiet. البدائل `version` و`-version` و`--version` و`-v` و`-V` دون حساسية لحالة الأحرف؛ أعلام الإصدار أوامر عامة وليست خيارات مرافقة لمعالجة أخرى.

### help

```powershell
tqsim
tqsim help
tqsim --help
tqsim -h
tqsim help split
tqsim split --help
tqsim merg -h
```

الموضوع اختياري وافتراضيه المساعدة الرئيسية؛ كل أمر له صفحة. البدائل `help` و`-help` و`--help` و`-h` و`--h` و`-?` و`/?` و`/help`، مع `help <command>` أو `<command> help`. تتجاوز المساعدة إلزام معاملات العملية والتحقق من قيمها، لكنها ترفض الأخطاء النحوية والأوامر والمواضيع والمعاملات غير المعروفة أو المكررة. لا تبدأ معالجة أو قراءة وصف أو طلب كلمة مرور أو تعديل صلاحيات أو إنشاء سجل أو اتصال GitHub أو إزالة. Quiet يبقي المساعدة وNoLogo يخفي الشعار. المعاملات المسماة بشرطة واحدة؛ `--File` غير مدعوم.

## القيم الافتراضية والمعاملات

| المعامل | الأوامر | الافتراضي |
| --- | --- | --- |
| `-ds` | split وmerg/merge | false |
| `-verify` | split وmerg/merge | true |
| `-encrypt` | split فقط | false |

لا يلزم كتابة القيم الافتراضية. تُقبل الكلمات true/false بحروف كبيرة أو صغيرة، مع اقتباس أو دونه؛ القيم الفارغة أو المفقودة أو yes/no/1/0 وغيرها خطأ استخدام. المفاتيح العامة وOverwrite معطلة افتراضيًا؛ لتمرير قيمة صريحة لمفتاح استخدم مثلًا `-Quiet:false` وليس `-Quiet false`. يدعم المحلل أيضًا `-Size:1GB`. اكتب الكلمات true/false للمعاملات النصية، ولا تمرر النص الحرفي `$true`/`$false`. اقتبس المسارات ذات الفراغات واستخدم `.\` قبل اسم يبدأ بشرطة. يُرفض التكرار.

يقدم [مرجع المعاملات](docs/PARAMETERS.md) كل القيم والأمثلة والتحذيرات. معاملات سكربت المثبت المباشر Repository وInstallRoot ليست معاملات أوامر tqsim. لا توجد `-Source` أو `-Password` أو `tqsim update -Check` أو merge -encrypt.

## التشفير

```powershell
tqsim split -File "D:\backup.iso" -Size "1GB" -Output "E:\EncryptedParts" -encrypt "true"
tqsim verify -PartsPath "E:\EncryptedParts"
tqsim merg -PartsPath "E:\EncryptedParts"
```

يطلب التقسيم كلمة مخفية من 12 إلى 1024 محرفًا وتأكيدها، والتحقق والدمج يطلبانها مرة واحدة تلقائيًا. استخدم طرفية تفاعلية دون إعادة توجيه الإدخال أو الإخراج. لا كلمة مرور عبر معاملات CLI ولا خدمة لاستعادتها.

يستخدم AES-256-GCM بسجلات حتى 4 MiB، وnonce فريد لكل مفتاح بطول 12 بايت، ووسم 16 بايت. اشتقاق PBKDF2-HMAC-SHA256 بعدد 600,000 دورة وملح عشوائي جديد 32 بايت، مع مفاتيح منفصلة للتشفير وHMAC للوصف. يصادق schema 2 البيانات والترتيب. احتفظ بالوصف لأنه يحمل الملح والتخطيط والمصادقة دون كلمة أو مفتاح صريح. تبقى الأسماء والأحجام والبصمات مرئية. الزيادة 28 بايت لكل سجل، والجزء الفعلي لا يتجاوز Size. للملف الفارغ وصف مصادق دون أجزاء.

الفشل في كلمة المرور أو المصادقة أو الأجزاء يمنع اعتماد نص جزئي وحذف المصادر. تُنشأ الملفات المؤقتة المفكوكة بصلاحيات مالك فقط وتزال عند الفشل؛ الإزالة ليست محوًا آمنًا. **المصادقة إلزامية حتى مع `-verify false`**؛ القراءة المستقلة شيء آخر. يبقى schema 1 غير المشفر دون أسرار. لم يخضع هذا التنسيق لتدقيق أمني خارجي. [المواصفات والقيود](docs/ENCRYPTED-FORMAT-v1.md).

## حذف المصدر

`-ds false` الافتراضي يبقي المصدر. `-ds true` يحذف مدخل التقسيم أو أجزاء الدمج المختارة ثم وصفها، بعد اكتمال الكتابة واعتماد المخرجات والفحوص اللازمة والقراءة المستقلة عند تفعيلها. الحذف لا رجعة فيه وليس محوًا آمنًا أو بديلًا لنسخة مستقلة. أثبت الاستعادة قبل حذف بيانات مهمة. إلغاء القراءة المستقلة يقلل الضمان حتى مع بقاء البصمات والمصادقة.

تُفحص هويات الملفات وأحجامها وتواريخها مع أقفال؛ تُرفض الأهداف الملتبسة والمشتركة والروابط غير الآمنة. حذف عدة ملفات ليس ذريًا. الفشل الجزئي يعلن المحذوف والمتبقي أو غير المؤكد، ويحفظ المخرج المكتمل وسجلًا خاصًا في `%LOCALAPPDATA%\Tqsim\Recovery`. النجاح يزيل سجله؛ فشل دون حذف لا يترك سجلًا بلا فائدة؛ تبقى السجلات الأخرى. بعد الانقطاع يلزم تحقق يدوي، ولا تُنفذ سجلات الاستعادة أو تعاد محاولتها آليًا.

قد يمنع الحذف ACL أو القراءة فقط أو قفل أو قيد آخر. مع ds=true فقط يمكن إضافة حق Delete لمعرف المستخدم على الملف المحدد إذا كان تعديل DACL مأذونًا أصلًا. لا تغيير لصلاحيات الأب أو القرص ولا FullControl على المصدر ولا استيلاء على الملكية أو تجاوز UAC. عند استمرار الرفض احتفظ بالمخرج وعالج الملفات الباقية بحساب مخول؛ قد تحتاج إذن مسؤول. لا توجد أداة رفع صلاحيات تلقائية. لا تكرر عملية ضخمة مكتملة لمجرد إعادة الحذف.

## التحقق

| الآلية | ما تفعله |
| --- | --- |
| فحوص التدفق الإلزامية | الأطوال وSHA-256 للأجزاء والكامل قبل الاعتماد |
| مصادقة التشفير | HMAC للوصف وكل سجل GCM دائمًا، حتى في الوضع السريع |
| `-verify true` | قراءة مستقلة إضافية واحدة؛ افتراضية للتقسيم والدمج |
| `-verify false` | تجاوز القراءة الإضافية فقط بضمان تخزين أقل |
| الأمر verify | فحص كامل دون استعادة أو حذف؛ يحتاج كلمة المرور للمشفر |

النجاح يثبت الاتساق عند القراءة، لا نسخة احتياطية أو توقيع ناشر أو منع تلف لاحق أو ضمان عتاد وطاقة. الوصف القديم ذو بصمة غير موقعة؛ احتفظ بنسخة موثوقة أو بصمة متوقعة مستقلة.

## بنية الملفات

قبل التقسيم يوجد `D:\backup.iso`. بعده مع الاحتفاظ بالمصدر:

```text
D:\
  backup.iso
  Output\
    backup.iso.part0001
    backup.iso.part0002
    backup.iso.tqsim.json
```

الدمج العادي يضيف `backup.iso` داخل Output ويبقي ملفات الأرشيف. بعد دمج ناجح مع ds=true يبقى هناك الملف المستعاد فقط:

```text
D:\Output\
  backup.iso
```

التقسيم المشفر يستخدم الأسماء نفسها مع أجزاء مشفرة ووصف schema 2:

```text
E:\EncryptedParts\
  backup.iso.part0001
  backup.iso.part0002
  backup.iso.tqsim.json
```

الدمج المشفر يضيف `E:\EncryptedParts\backup.iso` كنص مفكوك دون لاحقة جديدة أو Output متداخل. يبقي الأجزاء والوصف ما لم تُفعّل ds=true؛ النجاح مع الحذف يبقي الملف فقط. تحديد Output إلى `D:\Restored` يضع الملف هناك بدلًا من مجلد الأجزاء. احم صلاحيات المخرج.

## الأداء

أزال تحسين 1.0.5 القراءات الكاملة المكررة: قراءة مصدر واحدة للتقسيم، وفحص الأجزاء أثناء كتابتها في الدمج، ثم قراءة مخرج واحدة إضافية مع verify=true. الحذف لا يضيف مسح بيانات؛ تبقى فحوص الهوية والبيانات الوصفية. ذاكرة الملفات محدودة، لكن الوصف والأقفال يتناسبان مع عدد الأجزاء. يضيف التشفير كلفة اشتقاق أولية ومصادقة وتأطير.

قياسات تاريخية فعلية من 1.0.6 على Windows محلي وPowerShell 7، ببيانات عشوائية **5 GiB + 17 بايت**: تقسيم ودمج مشفر بأجزاء 1GB مع القراءة المستقلة استغرقا **35.113 و31.735 ثانية** (145.82 و161.34 MiB/s). الوضع السريع المشفر بأجزاء 2GB استغرق **22.158 و20.734 ثانية**. تشغيلات مفردة دون ضبط ذاكرة التخزين المؤقت أو معيار عتاد موحد؛ ليست سرعات مضمونة أو مقارنة تشفير معزولة. جُربت أجزاء فعلية 2GB و4GB. [القياسات الكاملة](docs/VALIDATION-v1.0.6.md) و[تحسين 1.0.5](docs/PERFORMANCE-v1.0.5.md). ليست اختبارات ضخمة أعيدت في 1.0.8، ولا ندعي تجربة فعلية 200GB أو 1TB.

## حل المشكلات

[دليل الأعراض والأسباب والحلول](docs/TROUBLESHOOTING.md) يغطي رفض الوصول والقفل والأجزاء المفقودة أو التالفة واختلاف البصمة وكلمة المرور والمصادقة والوجهة الموجودة والمساحة والتنسيق والإصدار والتحديث والتنظيف الجزئي والانقطاع والوصف المفقود. لا تعدل البصمات لإخفاء الفشل؛ احفظ البيانات الأصلية. استخدم Diagnostics لتفاصيل الخطأ وراجع المسارات قبل مشاركة السجلات.

الحالات: 0 نجاح، 1 فشل تشغيلي أو تحديث أو تنظيف، 2 استخدام أو معاملات، 3 وصف أو سلامة أو مصادقة. قد يصنف الجزء المفقود تشغيليًا أو ضمن السلامة حسب المسار؛ اعتبر كل حالة غير صفرية فشلًا.

قد يترك المثبت القديم مجلدي bin وversions وأشجار مجلدات فارغة دون علامة ملكية. يقبل المثبت المصحح هدفًا فارغًا أو هذه البنية المعروفة الخالية من الملفات دون حذف تكراري. الملفات المخفية والمجلدات غير المعروفة والروابط وعلامة الملكية التالفة أو غير المقروءة تمنع اعتماد المجلد؛ احفظ البيانات واختر InstallRoot آخر أو استعد علامة الملكية الصحيحة.

## التحديث وإلغاء التثبيت

```powershell
tqsim version -NoLogo
tqsim update
tqsim version -NoLogo
# فقط عند الرغبة في إزالة التطبيق المُدار:
tqsim uninstall
```

التحديث يفحص ويطبق إصدارًا مستقرًا أحدث ولا يملك وضع فحص فقط. الإزالة دون تأكيد تمس ملفات التطبيق المعروفة وPATH وتحفظ البيانات والمجلدات وسجلات الاستعادة. يحتاجان مؤشر ملكية تثبيت مُدار ولا يعملان على checkout المصدر. أعد فتح الطرفية بعد تغيير PATH. ليسا أمرين لتنظيف الأرشيف.

## الأمان

احفظ كلمات المرور ونسخ المصدر واختبر الاستعادة قبل الحذف. SHA-256 ليس نسخة مستقلة ولا مصادقة للوصف القديم. مصادقة التشفير لا تضمن سلامة التخزين مستقبلًا، والبيانات الوصفية مرئية. قد تبقى نسخ أسرار أو نصوص مفكوكة في النظام وذاكرته ولقطاته رغم مسح الذاكرة والإزالة بأفضل جهد. سجلات الاستعادة تحتوي مسارات وبصمات لا أسرارًا؛ راجعها قبل النشر. تظل صلاحيات Windows وUAC نافذة. الأعطال والتلف اللاحق والانقطاع أثناء حذف عدة ملفات ممكنة. لا شهادة أو تدقيق تشفير خارجي.

## الأسئلة الشائعة

| السؤال | الجواب |
| --- | --- |
| هل تدمج الأجزاء القديمة؟ | نعم، schema 1 محفوظ واختُبرت عينات فعلية من 1.0.2–1.0.5؛ احتفظ بالوصف الأصلي. |
| هل يمكن رفعها للسحابة؟ | نعم مع كل الأجزاء والوصف دون تعديل؛ Tqsim لا يرفع تلقائيًا. |
| هل أحتاج المصدر الأصلي؟ | لا؛ تحتاج الأجزاء والوصف كاملين وكلمة مرور المشفر. |
| هل يجب كتابة الافتراضيات؟ | لا؛ ds=false وverify=true وencrypt=false. |
| هل يدمج المشفر؟ | نعم باكتشاف تلقائي وطلب كلمة المرور. |
| ماذا إن نسيت الكلمة؟ | لا يستطيع Tqsim استعادة البيانات المشفرة. |
| هل يمكن حذف المصادر آليًا؟ | نعم مع ds=true بعد شروط النجاح والسلامة المطلوبة. |
| لماذا يفشل الحذف؟ | صلاحيات أو قراءة فقط أو قفل أو تغير هوية أو مشاركة غير آمنة؛ احفظ المخرج وعالج السبب. |
| هل يدعم أكبر من 4GB؟ | نعم بتدفق Int64؛ اختُبر 5 GiB+17 وأجزاء 4GB في 1.0.6. |
| أين يُحفظ المدموج؟ | بجوار الوصف والأجزاء مباشرة ما لم تحدد Output. |
| هل SHA-256 تلقائي؟ | نعم أثناء المعالجة، والقراءة المستقلة مفعلة افتراضيًا أيضًا. |
| هل info يثبت السلامة؟ | لا؛ استخدم verify. |

## التطوير والنشر والمساهمة

من المصدر شغّل `pwsh -NoProfile -File ./tqsim.ps1 help`. شغّل كامل الاختبارات باستخدام Pester 4.10.1 أو إصدار متوافق؛ Pester 3 غير مناسب لـPowerShell الحديث:

```powershell
Invoke-Pester ./tests
pwsh -NoProfile -File ./scripts/build-release.ps1
```

الحزمة `dist/Tqsim-v1.0.8.zip` وبصمتها `.zip.sha256`؛ يرفض البناء استبدال ZIP موجود ويستبعد بيانات الاختبار وأدوات القياس. [مصفوفة التغطية](docs/HELP-COVERAGE.md) و[نتائج الإصدار](docs/VALIDATION-v1.0.8.md). يتضمن 1.0.8 إصلاحات دورة التثبيت والإزالة ومشغل Windows. تبقى وظائف 1.0.7 والمساعدة وتنسيقات الأرشيف ومحرك البيانات والبصمات والتشفير دون تغيير.

النشر يدوي ويتطلب إذنًا. راجع الملفات المقصودة وأضفها وأنشئ commit على فرع الإصدار؛ ثم بعد الموافقة، بافتراض أن main الفرع المقصود وorigin للمستودع الرسمي:

```powershell
git status --short
git diff
# بعد المراجعة وcommit، وقبل تحديث المثبت العام:
git tag v1.0.8
git push origin v1.0.8
gh release create v1.0.8 ./dist/Tqsim-v1.0.8.zip ./dist/Tqsim-v1.0.8.zip.sha256 --repo SamiAlmouss/Tqsim --title 'Tqsim v1.0.8' --notes-file CHANGELOG.md
# بعد توفر الأصلين فقط، انشر المثبت المطابق:
git push origin main
```

بعد النشر المصرح اختبر أمر التثبيت العام نفسه في جلسات تجريبية من Windows PowerShell 5.1 وPowerShell 7، وتأكد من ظهور 1.0.8 عبر `tqsim version -NoLogo`. هذا الاختبار العام ينتظر النشر. يمكن للمثبتين استخدام `tqsim update` حينها. لا push أو tag أو نشر أو تثبيت تلقائي في هذه المهمة.
