SPLIT
  tqsim split -File <source> -Size <size> [-Output <directory>]
              [-ds <true|false>] [-verify <true|false>] [-encrypt <true|false>]

OPTIONS
  -encrypt      true or false (case insensitive). Default: false. Split only.
                true securely prompts twice for a 12..1024-character passphrase.
                AES-256-GCM encryption uses authenticated bounded records.
                There is no password/key command-line option or recovery service.
  -File         Original binary file; retained unless -ds true is explicit.
  -ds           true or false (case insensitive). Default: false, keep source.
                true deletes only after required streaming/publication checks
                and independent verification when enabled.
  -verify       true or false (case insensitive). Default: true.
                true reads back the split set once; false skips this extra pass.
                Streaming SHA-256, byte counts, safe publication and deletion
                identity checks remain mandatory. Omitted options use defaults.
  -Size         Positive integer bytes or B, KB/KiB, MB/MiB, GB/GiB, TB/TiB.
  -Output       Destination directory; defaults to Output beside the source.
  -BufferSize   Bounded I/O buffer in bytes, 4096..67108864 (default 4194304).
  -NoLogo       Hide branding; preserve operation output.
  -Quiet        Suppress routine output and progress; errors remain visible.
  -Diagnostics  Add exception type, source line, stack and inner exceptions.
  -NoColor      Disable Tqsim text colors. NO_COLOR is also respected.

SIZES AND INTEGRITY
  Units are binary: 1GB = 1GiB = 1,073,741,824 bytes.
  Decimal 1 gigabyte is 1,000,000,000 bytes; use -Size 1000000000 for that.
  Streaming uses bounded memory for data, Int64 counts and SHA-256 hashes.
  Parts and the .tqsim.json manifest are never silently overwritten.
  Empty input produces zero parts and the empty-stream SHA-256 manifest.
  Unencrypted part bytes and schema 1 remain unchanged and merge without secrets.
  Encrypted schema 2 accounts for 28 bytes framing/tag overhead per record;
  physical parts never exceed Size. Minimum encrypted Size: 29 bytes.
  -verify false never disables encryption authentication. Keep your password:
  if lost, your encrypted archive cannot be recovered. Do not redirect prompts.

DELETE SOURCE WARNING
  Delete Source is irreversible. Use true only when the generated data has
  been verified and is stored safely. SHA-256 is not an independent backup
  and does not guarantee future storage durability. Extra verification I/O
  and locks are required. Unsafe links/identities cause deletion to fail closed.
  Successful cleanup removes its record; partial/interrupted cleanup keeps a private recovery record. No automatic retry.
  -ds true -verify false is an explicit fast mode with less integrity assurance:
  no independent output read-back occurs. Successful writes and flush do not
  guarantee durable storage under every device or power-failure condition.

EXAMPLES
  tqsim split -File "D:\backup.iso" -Size 500MB
  tqsim split -File "D:\backup.iso" -Size 1GB
  tqsim split -File "D:\backup.iso" -Size 2GB -Output "E:\Parts"
  tqsim split -File "D:\backup.iso" -Size 4GB -NoLogo
  tqsim split -File "D:\backup.iso" -Size 2GB -ds false
  tqsim split -File "D:\backup.iso" -Size 2GB -ds true
  tqsim split -File "D:\backup.iso" -Size 2GB -ds true -verify false
  tqsim split -File "D:\backup.iso" -Size 2GB -encrypt true

HELP
  tqsim help split
  tqsim split --help
