TQSIM — SECURE FILE SPLITTER & MERGER
  Version: {{VERSION}}

USAGE
  tqsim <command> [options]

COMMANDS
  split       Split a file; optionally encrypt its parts
  merg        Reconstruct the original file from its parts
  merge       Alias for merg
  verify      Check all parts and the original SHA-256
  info        View metadata without checking parts
  update      Check and apply a managed installation update
  uninstall   Remove owned application files and PATH entry
  version     Display application version
  help        Display main or command-specific help

GLOBAL OPTIONS
  -NoLogo       Hide branding; requested help/results remain
  -NoColor      Disable Tqsim colors (also NO_COLOR)
  -Quiet        Hide routine output/progress; retain help/errors
  -Diagnostics  Add exception type, source line and stack on errors
  Help: help, -help, --help, -h, --h, -?, /?, /help
  Version: version, -version, --version, -v (case insensitive)

QUICK START
  tqsim split -File "D:\backup.iso" -Size 1GB
  tqsim verify -PartsPath "D:\Output"
  tqsim merg -PartsPath "D:\Output"
  Split defaults to Output beside the source. Merge restores directly
  in the selected manifest directory unless -Output is supplied.
  Existing restored files require explicit merge -Overwrite.

SECURITY OPTIONS
  Split/merge: -ds true|false (Default: false), keep sources.
  Split/merge: -verify true|false (Default: true), read output back once.
  Split only: -encrypt true|false (Default: false), hidden password prompts.
  Encrypted merge/verify detect encryption automatically; authentication
  stays mandatory with -verify false. Old plain archives need no password.
  Lost passwords cannot be recovered. Source deletion is irreversible.

GET HELP
  tqsim help split
  tqsim merg --help
  tqsim verify -h
  No arguments shows this page. Help never starts an operation.
  Named options use one dash; quote paths with spaces. true/false may
  be quoted or unquoted; invalid values are usage errors.
  Exit codes: 0 success, 1 operational failure, 2 usage, 3 integrity failure.
